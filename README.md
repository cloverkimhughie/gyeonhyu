# Gyeonhyu Chinese Vocabulary

말해보카처럼 짧은 문제를 반복해서 풀며 중국어 단어를 학습하는 웹 앱의 초기 버전입니다.

## 현재 기능
- 중국어 단어 카드와 병음/뜻 확인
- 중국어 → 한국어 4지선다
- 한국어 → 중국어 입력 문제
- 정답/오답 즉시 피드백
- 연속 정답(콤보)과 학습 진도 표시
- 오답 단어 다시 학습
- 브라우저 음성 합성(Web Speech API)을 이용한 중국어 발음 듣기
- 학습 세션 중 통계 표시
- 기본 단어 데이터는 `app.js`에서 쉽게 추가/수정 가능

## 실행
`index.html`을 브라우저에서 열면 바로 실행할 수 있습니다.
