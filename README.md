# Gyeonhyu Chinese Vocabulary

한국어 예문의 문맥을 보고 중국어 문장에 빠진 핵심 단어 하나를 직접 떠올리는 중국어 어휘 학습 웹 앱입니다.

## 주요 기능

- 한국어 예문과 중국어 빈칸 문장으로 학습
- 중국어 단어 직접 입력, 병음 힌트, 정답 보기
- 완성 문장·병음·뜻 확인 및 중국어 음성 듣기
- 연속 정답, 진도, 정답률, 오답 복습
- **문제 만들기** 화면에서 나만의 문장 문제 추가
- 중국어 완성 문장에서 정답 단어 위치를 자동으로 찾아 빈칸 생성
- 직접 만든 문제 수정·삭제 및 `내 문제만 학습`
- 브라우저 `localStorage`에 직접 만든 문제 자동 저장

## 문제 만드는 법

1. 상단의 `문제 만들기`를 누릅니다.
2. 한국어 예문, 중국어 완성 문장, 정답 단어, 병음, 뜻을 입력합니다.
3. 빈칸 미리보기를 확인하고 `문제 저장`을 누릅니다.
4. 저장한 문제는 기본 문제와 함께 출제되며, `내 문제만 학습`도 가능합니다.

직접 만든 문제는 현재 사용 중인 브라우저와 기기에 저장됩니다. 다른 브라우저나 기기에는 자동으로 공유되지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행할 수 있습니다.
