# Gyeonhyu Chinese Vocabulary

한국어 예문의 문맥을 보고 중국어 문장에 빠진 핵심 단어 하나를 직접 떠올리는 중국어 어휘 학습 웹 앱입니다.

## 학습 방식

예시:

- 한국어: 나는 매일 중국어를 공부해.
- 중국어: 我每天 □□ 中文。
- 정답: 学习
- 정답 확인 뒤 병음, 뜻, 완성 문장을 함께 복습

## 현재 기능

- 한국어 예문을 먼저 제시
- 대응되는 중국어 문장에서 핵심 단어 1개를 빈칸 처리
- 중국어 단어 직접 입력
- 병음 힌트
- 모를 때 정답 보기
- 정답 뒤 완성 중국어 문장과 문장 전체 병음 표시
- 핵심 단어의 병음과 한국어 뜻 표시
- 완성 문장 중국어 음성 듣기
- 연속 정답, 진도, 정답률 표시
- 오답 문장만 다시 학습
- 기본 학습 데이터는 `app.js`의 `LESSONS` 배열에서 수정 가능

## 실행

`index.html`을 브라우저에서 열면 바로 실행할 수 있습니다.
